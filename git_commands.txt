1. git init
   Initializes a new, empty local Git repository inside the current project folder.

2. git add <file>
   Stages new or modified files so they are prepared for the next commit.

3. git commit -m "<message>"
   Records a permanent snapshot of the staged changes in the repository history with a descriptive message.

4. git branch <branch-name>
   Creates a new branch pointer to allow isolated development without affecting the main branch.

5. git checkout <branch-name>
   Switches the active working directory to the specified branch.

6. git merge --no-ff <branch-name>
   Integrates changes from the specified branch into the current branch while preserving a merge commit in history.

7. git log --oneline --graph --all
   Displays a compact visual commit history showing all commits, branches, and merges across the repository.

8. git status
   Displays the current state of the working directory and staging area, confirming tracked, modified, and ignored files.

9. git revert HEAD
   Safely undoes the most recent commit by creating a new inverse commit that reverses its changes.

10. git remote add origin <url>
    Connects the local Git repository to a remote GitHub repository under the alias 'origin'.

11. git push -u origin main
    Uploads all local commits and branch history from the local 'main' branch to the remote GitHub repository.
